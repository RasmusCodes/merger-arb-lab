# Offline sample data

- `synthetic_daily.csv`, `synthetic_quotes.json`: **synthetic** prices generated by `scripts/make_sample_data.py`
  (seeded correlated GBM, then a target that trades at 4.5 x acquirer x (1 - noisy discount) after a fake
  "unaffected" date). They are not market data and exist only so that the whole pipeline, the tests and the dashboard
  run without network access or licensed data. Use them with `MERGERARB_DATA=sample`. Every surface then shows a
  "SYNTHETIC SAMPLE DATA" banner, and the trade signal is forced to NO TRADE.
- `treasury_par_curve_2026.csv`: the real US Treasury daily par yield curve for 2026 (public domain,
  home.treasury.gov). It is the fallback discount curve when no fresh pull exists.
